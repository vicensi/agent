TOOL 1
list_metrics
Retorna catálogo completo das 8 métricas. Usar antes de query_metric quando não sabe o nome exato ou quer comparar métricas similares.
TOOL 2 — CAMINHO PREFERENCIAL
query_metric
Consulta métrica pré-definida com SQL gerado. 8 métricas: delivered_revenue, gross_revenue, net_revenue, returned_revenue, delivered_orders, avg_order_value, return_rate, active_customers_30d.
TOOL 3 — ESCAPE HATCH
run_sql_readonly
SQL livre com validação de segurança (sqlglot AST). Usar apenas quando query_metric não cobre — ex: JOIN entre fct_orders e dim_products para análise por categoria.
TOOL 4
get_lineage
Retorna origem, transformações e colunas de um modelo dbt. Usar antes de escrever SQL livre para verificar se uma coluna existe e de onde vem.
TOOL 5 — NOVA (Phase 7)
plot_chart
Registra spec de gráfico (bar/line/pie) após obter dados. Não executa query — armazena em charts_log. AskResponse.charts[] é lido pelo Streamlit para renderizar Plotly inline.
